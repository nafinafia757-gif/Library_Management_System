## Library_Management_System:

## Project Description:

This project is developed using MySQL. It is used to manage the details of a library, including books, customers, employees, branches, book issues, and returns.

### Database Name:

library

### Tables:

1. Branch
   
2. Employee
 
3. Books
 
4. Customer
   
5. IssueStatus
 
6. ReturnStatus

### Features:

- Store book information.
  
- Store customer details.
  
- Store employee details.
  
- Manage branch information.
  
- Track issued books.
  
- Track returned books.
  
- Generate reports using SQL queries.

### Operations Performed:

- Created database and tables.
  
- Inserted sample data.
  
- Used primary and foreign keys.
  
- Retrieved data using SQL queries.
  
- Used JOIN, COUNT, GROUP BY, and HAVING clauses.

### Queries Included:

1. Available books.
   
2. Employee salaries in descending order.
 
3. Issued books and customer names.
  
4. Number of books in each category.
   
5. Employees with salary above Rs. 50,000.
   
6. Customers registered before 2022 and not issued books.
   
7. Employee count in each branch.
 
8. Customers who issued books in June 2023.
 
9. Books containing "History" in the title.
 
10. Branches having more than 5 employees.
 
11. Branch managers and branch addresses.
  
12. Customers who issued books with rental price above Rs. 25

### Tools Used:

- MySQL Workbench
  
### Conclusion:

The Library Management System was successfully created using MySQL. This project helps manage books, customers, employees, and library transactions efficiently. It also demonstrates the use of database concepts such as tables, primary keys, foreign keys, joins, and SQL queries.
